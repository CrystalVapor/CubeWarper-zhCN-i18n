# Cube Warper 解压覆盖式汉化补丁

适用于 Minecraft 1.20.1 / Forge 的 Cube Warper 整合包，译文快照版本为 2026-10-12。

## 安装

1. 完全退出游戏，备份实例中的 `config/ftbquests`、`kubejs` 和 `patchouli_books`。解压覆盖安装会替换同名文件；已有的自定义修改请先保存。
2. 将补丁 ZIP 内的全部文件直接解压到整合包实例根目录，选择覆盖同名文件。解压后的 `config`、`kubejs`、`patchouli_books`、`resourcepacks` 应与实例原有的 `mods` 目录处于同一层。
3. 启动游戏，将语言设置为简体中文。在“选项 → 资源包”中启用以下两个包，并将它们移动到已选资源包列表顶部：

   | 从上到下 | 资源包 |
   | --- | --- |
   | 1（最高优先级） | `CubeWarper-Chinese-Bilingual` |
   | 2 | `Minecraft-Mod-Language-Modpack-Converted-1.20.1.zip` |

   确认后等待资源重载。其他资源包可保留在这两个语言包下方。

ZIP 内直接包含游戏相对路径。请将全部内容解压到实例根目录；此 ZIP 本身包含多种游戏文件，资源包菜单只需启用上述两个包。本安装方式无需运行 PowerShell 或 Python，语言和资源包顺序由游戏菜单设置。

补丁自带自动汉化资源包快照。若本地同名自动汉化 ZIP 已更新，可以在解压时保留该本地文件。本地双语补丁应始终保持最高优先级。

## 恢复

使用安装前的备份还原被覆盖的文件，并在资源包菜单中停用 `CubeWarper-Chinese-Bilingual`。手动覆盖安装的备份由使用者保存；需要自动备份和恢复时，可使用项目提供的脚本安装包。

本补丁保持任务 ID、配方和函数逻辑。实际游戏排版与部分手册分页仍待进一步验证。
